# Reproducibility checklist

Before archival/public release, verify that the repository contains:

- [ ] Exact Python version
- [ ] Exact versions of NumPy, SciPy, pandas, Matplotlib, and any additional packages actually used
- [ ] Complete source code
- [ ] Fixed random-number seeds
- [ ] Solver choice and tolerances
- [ ] Initial conditions and simulation intervals
- [ ] Nominal parameter values
- [ ] Parameter uncertainty ranges and distributions
- [ ] Latin Hypercube sampling configuration
- [ ] Sobol sampling configuration and bootstrap settings
- [ ] Structural-model identifiers
- [ ] Spectral channel centers, line shapes, and provenance
- [ ] Detector-response functions
- [ ] Raw simulation outputs
- [ ] Processed summary tables
- [ ] Scripts reproducing every figure and table
- [ ] Final manuscript citation
- [ ] Repository release tag
- [ ] Permanent archival DOI (e.g., Zenodo) if used for publication
- [ ] Selected software/data license
